UpdateSWH shows whether the source code repository you are browsing is archived in Software Heritage, the universal archive of source code, and lets you archive it with one click when it is missing or out of date.

A coloured button on the right edge of a repository page shows its archival state:

- green: archived and up to date. Click to open the archived copy.
- yellow: archived, but the repository has changed since. Click to request an update; right click to open the last archival.
- grey: not archived yet. Click to request archival.
- light green: an archival is in progress. Click to open the save request queue; right click to open the last archival, when there is one.
- brown: the last archival attempt failed. Click to try again; right click to open the last archival.
- orange: an API rate limit was reached. An access token, set on the options page, raises the limit.
- red: the forge API request failed, for example on a private repository.
- blue: the archive could not be reached. Click to open archive.softwareheritage.org and check.

It works on GitHub, GitLab.com and Bitbucket, and on a set of public GitLab, Gitea and Forgejo instances listed on the options page. Other instances can be added there. Access to each forge is asked for when it is first needed, not at install: the options page opens on first install and grants access to all built-in forges with one button.

More information: https://www.softwareheritage.org/browser-extensions/
